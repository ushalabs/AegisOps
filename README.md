# AegisOps

AegisOps is a modular AI-powered platform for incident detection, investigation, root-cause analysis, human-approved remediation, recovery verification, and postmortem generation.

## Status

Currently under active development.

### Current Phase

Phase 0 — Project Foundation

## Planned Core Stack

- Python
- FastAPI
- PostgreSQL
- pgvector
- Docker
- Docker Compose

## Development Goal

Build AegisOps incrementally while learning the architecture and engineering concepts behind each component.
